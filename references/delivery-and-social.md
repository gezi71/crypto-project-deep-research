# 双语研究与社交媒体交付

适用于 Analyze、Deep Dive、Compare、Update、Discover。完成相应模式的研究后读取本文件；共用研究结果，不为英文版本重跑一次研究。

## 默认四份产物

| 文件 | 内容 |
| --- | --- |
| `report.zh-CN.md` | 中文报告，保留必要英文术语，覆盖该模式全部要求 |
| `report.en.md` | 自然英文完整报告，与中文在研究范围、证据、分析深度及结论上对应 |
| `social-post.zh-CN.md` | 可独立阅读、适合复制发布的中文帖文 |
| `social-post.en.md` | 面向英文读者重写的同一篇帖文，保持相同事实和判断强度 |

默认 Markdown，各语言分文件，不在同一段落逐句中英交替。放入同一个带项目/主题与时间戳的目录；不覆盖旧文件。证据、缺口、计算可以共用一套并从两份报告链接，不为双语重复生成相同底稿。最终回复简述研究结论或变更并链接四份产物，无需在聊天中重复全文。

用户明确要求单一语言、仅报告、仅帖文、特定平台/篇幅/文体时优先遵守；这不构成取消之后任务的默认双语偏好。不要因缺少平台而阻塞交付：默认一篇连贯的通用长帖，中文约 600–1,000 字、英文约 400–650 词，仅作篇幅参考，信息不足时缩短，不凑字数。用户指定短帖/串帖时按该格式改写，不默认额外生成多平台、多标题或更多版本。

## 自动数据配图

交付前读取 [自动配图规范](data-charts.md)。完整长报告默认3张数据图，每篇短帖1张、长篇帖文3张；Discover/候选筛选不强制配图。中英文使用同一数据与计算，分别生成对应语言图片，可复用报告中的相关图；正文嵌入PNG，摘要链接PNG、CSV与可复现脚本。数据不足说明缺口，不凑数。

## 版本一致性

从同一份已经完成核验与计算的研究生成双语版本。名称、合约、单位、币种、截止日期/时区、期间、供应口径、公式、情景、评分、Verdict、Confidence 和证伪条件一致。中文“亿/万”和英文 billion/million 转换后复核；不要把 1 亿误写成 1 billion，或将百分点变化译为相对增长。

Fact / Estimate / Interpretation / Assumption 的性质、官方声称/单源/冲突/未核验状态、N/A、不适用和计划/已执行的差别在英文中保留。不能在翻译时将“暂无可靠数据”变成“没有收入”，也不能把条件模型变成预测。完整英文版不是中文报告的短摘要。

只改写、翻译已有报告时，保留原报告的数据截止，不将旧价格或旧事件称为当前。若用户要求更新到最新，先按 Update 重新核验；不能为帖文加入未进入报告的新事实。

## 帖文的编辑方式

报告服务于核验和决策，帖文服务于公众理解；从一个重要、证据支持的问题或判断切入，形成能独立阅读的论证。不要逐章压缩报告、堆评分表、附全部底稿或用“本文将从若干方面分析”开场。

推荐叙事顺序，可随主题调整：

1. 用具体观察或核心判断开头，说明为什么现在值得关注。
2. 简洁解释项目做什么、谁使用和付钱，以及真正不同的地方。
3. 用 2–4 个最能改变判断的证据支持主线；重要数字就近带期间、单位和直接来源。
4. 解释使用/收入如何或为何不能传导给 Token；无 Token 项目说明研究的是业务，不暗示发币。
5. 纳入最强反方、影响结论的关键缺口，以及下一步可观察的验证/证伪信号，以清楚的研究判断收尾。

帖文中自然表达不确定性，不必逐句贴四类英文标签，但不能改变证据性质。只保留与主线有关的数字；不因追求传播性移除关键条件、供给压力或 Low Confidence 的原因。计算例子就近说明“假设/示例”，尤其是通缩门槛、情景估值、潜在卖压和收益年化；标题与开头也必须保留会改变结论的条件。

用短段落、具体语言和克制的观点表达；英文按英语阅读习惯重写，避免逐字翻译。可以使用简洁标题；默认不加表情、标签堆砌、营销口号、价格保证、买入号召、空投承诺、虚构经历/仓位或夸张的“下一个百倍”。不在正文写“以下是可发布版本”等编辑说明。

帖文注明研究截止日期；在关键事实附近放直接来源链接，可在末尾汇总少量主要来源，避免只有报告本地路径或内部证据 ID。没有公开报告 URL 时不要编造链接。帖文必须在不打开完整报告的情况下仍能理解核心论证与限制。

## 各模式边界

- **Analyze / Deep Dive**：两份完整研究 + 两份围绕最重要发现的帖文；不以四份文件为由降低原研究深度。
- **Compare**：两份统一口径比较报告 + 两份比较帖文；不为每个候选额外生成四份，也不强选赢家。
- **Update**：两份包含真实差分与 Thesis 状态的报告 + 两份突出变化的帖文；没有基线时明确不能确认变化。
- **Discover**：两份按 discover.md 编写的发现报告 + 两份围绕样本和信号的帖文；不展开 31 模块或增加投资评级。不把未排名观察项改成“Top 10”，不把研究优先级改成买入排序，也不把样本写成全市场。
- **只要帖文/已有报告转帖**：从已有有日期的研究生成所需语言帖文，不重做无关研究，不自动补造双语报告。关键材料不足时缩小论点或说明限制。

## 交付前核对

- 默认四份文件齐全；或用户指定例外已落实。
- 配图数量或少出图原因已交代；PNG已运行生成并目检，图与正文/双语数据一致，来源、CSV和脚本链接有效。
- 两份报告内容覆盖对应，关键数字、单位、时点、评级和限制一致；底稿链接有效。
- 每篇帖文只有一条清楚主线，独立可读，事实可追溯，观点/假设与事实不混淆。
- 传播版本没有删去足以反转判断的反方或缺口，没有加入报告以外的新结论。
- 两种语言同样保留模式边界与不确定性，只交付草稿，不自动发布到任何账户。
