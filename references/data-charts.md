# 自动数据配图

## 触发与数量

Charts are generated when they materially improve understanding, validation, comparison, or communication. There is no mandatory chart count.

- Research Package 可以有 0 张、1 张或多张图；例如收入/用户趋势、TVL 构成、激励、市场份额、供应/解锁、Treasury、估值倍数、排放或协议与 Token 经济的比较，只有能帮助验证或理解时才画。文字或表格更清楚时无需图，零图不构成缺项。
- 可选长短文同样没有图数配额。Use as many charts as materially improve the piece, and no more. 由证据形态、分析需要、发布形式与读者价值决定；可复用相关图和同一 CSV/计算/脚本，按实际需要生成对应语言 PNG。配图不触发未请求的文章生成。
- Discover 默认无需图表，仅当明显有助候选比较或判断时生成；如生成图，保留观察样本、未排名及不可比限制，不将研究优先级画成投资排名。Compare 不按项目倍增图数；Update 无历史基线时不能伪称差分。数据不足记录缺口，不以凑图补造数据。
- 在研究笔记或所请求文章的对应论点附近嵌图，从交付摘要链接实际图片、数据与脚本。只转写已有报告时先复用原证据；补查遵守原截止日，新数据先进入研究底稿，不静默改变结论。资金流示意图按解释需要保留，无须计数。

## 取数与论证

- 配图是实际生成的统计图，不只列图表建议。选择最能支持核心论点、彼此不重复的趋势、对比、占比、估值或情景图；不以装饰插画替代数据图。用户明确要求的数量、格式、语言优先。
- 优先复用已核验的数据与计算；缺少关键输入时，围绕当前论点有限补查原始披露或可靠公开数据。不为凑图扩张研究、绕过访问限制或引入付费依赖；遵守当前任务截止日。找不到可靠数据、图不能增强论证或工具不可用时可不出图，说明实质数据或工具缺口，不编造数字或交付空白占位图。
- 每个绘图值可追溯至来源 URL、原始定位、期间/截止日、单位、币种及口径；计算保留输入与公式。CSV 留来源关联，或以稳定行/系列 ID 对应证据台账。缺失值保留为空，不补零；不在图中用连线掩盖缺失区间。
- 区分已实现事实、管理层口径、估算、预测和情景假设；在图例/注释就近标注，不能靠正文远处的免责声明补救。统一比较期间与定义；不可比时明确限制或放弃该图。来源冲突与样本范围随图保留。

## 绘制与交付

- 用 Python 的 matplotlib 等确定性绘图库或可用的等价工具实际绘制；不用生成式图片工具绘制数字、坐标或数据。按数据关系选择图型，避免误导比例的坐标、3D效果或无必要双轴；条形图从零起点，其他截断坐标须明确。
- 图中文字跟随所在正文语言。采用统一、简洁、适合研究阅读或发布的浅色风格、克制配色与清楚层次；标题直接说明观察，标注轴/单位、期间/截止日、币种（适用时）与简短来源，完整来源链接放图注。图表可以独立阅读，标题不夸大证据。
- 每张保存高分辨率 PNG（建议宽度至少 1600 px）、实际绘图数据 CSV 和可复现绘图脚本（如 Python）；放在交付目录的 `charts/`，已有文件不覆盖。脚本读取随附 CSV、记录必要依赖/运行方式，不依赖临时缓存、隐藏绝对路径或密钥。公开图不显示内部证据 ID、本地路径等实现信息。
- 在正文对应论点附近嵌入 PNG 并附图注/来源，最终答复展示图片或提供可点击预览；另链接 CSV 与脚本，编辑底稿中说明图与论点的关系。不要仅给代码、文件名或待制作建议并声称已出图。
- 交付前实际运行脚本并打开每张 PNG，核对数值、单位、轴、图例、缺失/预测标识与正文一致；检查字体无缺字、标签不重叠，并缩至手机阅读宽度确认可读。修正后再交付；未运行或未目检须如实说明，不把结构校验当作图像验证。
