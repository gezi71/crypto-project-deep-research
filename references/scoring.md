# 评分、Verdict 与 Confidence

评分是有依据的定性框架，不是精密测量。默认整数 0–10；核心证据不足或不适用写 N/A，不能填 5。所有分数高分均表示更好。

## 11 项评分

| 项 | 主要依据 |
| --- | --- |
| Project Quality | 需求真实性、协议必要性、交付与总体完整性；和下面分项有关，不能假装统计独立。 |
| Product | 可用性、用户任务完成、成熟度、可靠性与留存。 |
| Growth | 无补贴需求、付费/留存和多窗口趋势；原始地址增长不能单独支持高分。 |
| Economics | 外部付费、保留收入、成本、补贴后可持续性、收入质量。 |
| Tokenomics | 流通、集中、分配、稀释、解锁透明度与激励对齐。 |
| Token Value Capture | 已执行、持久、可验证的持币人价值归属；提案和治理叙事不能等同现金权。 |
| Moat | 结构性竞争优势、可持续性和侵蚀难度。 |
| Team | 可验证能力、执行、诚信与交付；匿名不自动低分，名气不自动高分。 |
| Decentralization | 实际控制、升级/暂停、退出、验证者/签名人独立性。 |
| Valuation | 同权益、同口径下的价格吸引力和安全边际；高分=更有吸引力，不是估值更高。 |
| Risk | 风险韧性/安全程度；高分=更安全。分数旁同时列主要残余风险。 |

通用锚点：0–2=已证实存在严重缺陷；3–4=明显薄弱；5–6=中等且有重大权衡；7–8=证据支持的强项；9–10=多维度经验证的突出质量。缺证据不等于已证实缺陷，必须 N/A。

每项输出 `分数或 N/A | Fact/Estimate/Interpretation | 理由/证据 | Confidence`，评分本身标为 Interpretation。

## Overall Score

默认为适用且证据足够维度的等权均值（保留 1 位小数），披露有效维度数/适用维度数与排除项。此均值包含相关维度，不能解释为成功概率。

若有 Token，Token Value Capture、Tokenomics、Economics、Valuation 任一缺关键证据，或有效维度少于适用维度的 70%，Overall Score 写 N/A，说明为何不能可靠汇总；仍给有证据分项。未发币公司 Tokenomics/Token Value Capture 不适用；公司估值未知则 Overall Score 也 N/A。

双 Verdict 独立判断，不能机械由 Overall Score 映射；强产品不得掩盖无捕获或过度稀释的 Token。

## Research Verdict

仅选择以下六项；未发币 Token 为不适用，是范围状态而非第七种评级。

| Verdict | Protocol 判断 | Token 判断 |
| --- | --- | --- |
| Exceptional | 经验证的突出需求、经济质量和持久优势 | 捕获、稀释、定价与风险均有显著优势且证据充分。 |
| Strong | 多项强证据，主要风险可识别且可承受 | 已验证价值路径和相对有吸引力定价，存在可解释风险。 |
| Interesting | 有潜力但关键条件尚待验证 | 存在可研究的非对称性，但依赖未兑现条件。 |
| Neutral | 证据混合或无明显质量优势 | 当前价格与风险/机会大体均衡，或关键证据不足无法形成方向判断。 |
| Weak | 产品/经济/控制有明显薄弱环节 | 捕获、供应或价格明显欠佳。 |
| Avoid | 有充分证据支持不可接受的重大风险 | 重大失效、不可接受尾部风险或权利/流动性问题。 |

Neutral 因证据不足时必须配 Low Confidence 和阻断判断的缺口。Exceptional 需要 High Confidence。Avoid 不能仅因匿名或缺数据下结论。

未发币公司用 Protocol 栏评价项目/业务质量并说明字段映射；Token 不适用。独立给 Business Quality、Token Quality、Token Valuation 的文字判断，避免把 Protocol 与公司混为一体。

## Confidence

- **High**：身份与关键机制已验证，影响结论的动态数据新鲜且多源一致，少量未知不改变方向。
- **Medium**：主体清晰，部分数据单源/有合理口径差异，结论仍有支持但敏感性较大。
- **Low**：关键供应、收入、控制、权利或估值缺失/冲突/过期，或依赖高比例假设。

可分别给 Protocol 与 Token Confidence，再给总体 Confidence；总体不能高于限制核心判断的关键证据。不能因高风险而自动低信心：风险大小与对其判断的把握是不同概念。

每次指出：可靠数据、缺失与冲突、关键假设、最能提升信心的新证据。评分与评级只反映报告截止日的研究判断。
